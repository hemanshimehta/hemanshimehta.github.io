# Hemanshi Mehta — Research & Insights

A responsive portfolio featuring consumer insights and academic research projects, experience, methods, and CV downloads.

## Publish with GitHub Pages

1. Create a public GitHub repository named `portfolio` (or use a new name of your choice).
2. Upload the contents of this folder directly to the repository root, including index.html, style.css and both CV files. Do not upload the ZIP itself.
3. Commit the uploaded files to the main branch.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose main and /(root), then Save.
7. Wait for GitHub to display the published website address in Settings → Pages. Publishing can take up to 10 minutes.

GitHub Pages is available for public repositories on GitHub Free. Hosting is independent of a ChatGPT subscription. The repository files and downloadable CVs will be public, including the contact details within them.

## Editing

Edit index.html for content and style.css for appearance. Keep the CV filenames unchanged when replacing them, or update their links in index.html. Commit changes to main to update the live site.

No installation, build process, API keys or paid services are required by this website.

Official setup guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
